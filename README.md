# Оптимизация размеров BERT модели для NER с помощью факторизации и дистилляции

# Стек
Python, PyTorch, Hugging Face Transformers, Datasets, Seqeval, Google Colab, Knowledge Distillation

# Описание проекта
Данный проект посвящен реализации и сравнению методов уменьшения размеров BERT модели для задачи Named Entity Recognition (NER) на датасете CoNLL-2003. В рамках проекта используются следующие подходы:

- Факторизация word embeddings — SVD разложение большой матрицы эмбеддингов на компактные факторы

- Fine-tuning факторизованной модели — дообучение сжатой модели с сохранением качества

- Knowledge Distillation — обучение компактной "ученик" модели на знаниях большой "учитель" модели

- Многокомпонентная loss функция — комбинация hard labels и soft logits с temperature scaling

Проект включает предобработку данных с выравниванием BIO меток, обучение моделей различной компактности и их оценку на стандартных NER метриках.

# Цель проекта
Цель проекта — создать компактные модели для NER, минимизируя требования к памяти и вычислениям при сохранении высокого качества распознавания именованных сущностей. В частности, планируется:

- Исследовать влияние SVD факторизации на качество word embeddings при сильном сжатии

- Оценить эффективность knowledge distillation для создания мини-моделей с приемлемым качеством

- Обеспечить возможность развертывания моделей на устройствах с ограниченными ресурсами

- Разработать полный пайплайн от предобработки данных до готовых предсказаний 

# Основные компоненты системы

- Датасет: CoNLL-2003 с BIO разметкой именованных сущностей (14k train, 3.4k test)
- Базовая модель: bert-base-cased с предобученными весами для NER

# Оптимизация:

- Факторизованные word embeddings через PCA-lowrank разложение

- Компактная "ученик" модель с уменьшенной архитектурой (меньше слоев, размерностей, голов)

- Дистилляция знаний с комбинированной функцией потерь (CE + KL-divergence)

Оценка: seqeval F1-score по BIO тегам (PER, ORG, LOC, MISC)

# Используемые данные
- Датасет CoNLL-2003 для Named Entity Recognition, разбитый на train и test множества.
- BIO разметка 9 классов: O, B-PER/I-PER, B-ORG/I-ORG, B-LOC/I-LOC, B-MISC/I-MISC.

# Результаты и выводы
- Реализованы методы факторизации эмбеддингов и knowledge distillation для создания компактных NER моделей.
- Факторизация word embeddings обеспечивает сильное сжатие при минимальной потере качества.
- Дистилляция знаний позволяет создать мини-модели пригодные для production на устройствах с ограниченными ресурсами.
- Разработан полный пайплайн от сырых данных до предсказаний
